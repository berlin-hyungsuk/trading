# Trading App

A Next.js application for real-time trading.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build & Production

Build for production:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
